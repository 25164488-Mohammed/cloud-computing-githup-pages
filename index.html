القسم الأول • Introduction

الحوسبة السحابية وعلاقتها باستضافة المواقع

تمثّل الحوسبة السحابية (Cloud Computing) نموذجاً لتوفير موارد الحوسبة — مثل الخوادم والتخزين والشبكات ومنصات النشر — عبر الإنترنت عند الطلب، مما غيّر جذرياً طريقة استضافة المواقع وإتاحتها للمستخدمين.

مفهوم الحوسبة السحابية

تتيح الحوسبة السحابية للمطورين والمؤسسات الاستفادة من بنية تحتية جاهزة ومُدارة سحابياً بدلاً من شراء أجهزة خوادم فعلية أو الانشغال بإعدادها وصيانتها وتحديثها المستمر.

التحول في استضافة المواقع

انتقلت استضافة الويب من الخوادم التقليدية التي تتطلب تهيئة يدوية لنظام التشغيل وخادم الويب وشهادات الأمان، إلى خدمات سحابية مؤتمتة تختصر الطريق من كتابة الشيفرة إلى النشر العام.

استضافة المواقع الثابتة سحابياً

تُعدّ استضافة المواقع الثابتة نموذجاً عملياً مباشراً للحوسبة السحابية؛ إذ تركز المنصة السحابية على تسليم ملفات الواجهة (HTML, CSS, JS) بسرعة وأمان عبر الشبكة دون إدارة خادم تطبيقات.

القسم الثاني • What is GitHub Pages?

ما هي خدمة GitHub Pages؟

خدمة استضافة مواقع ثابتة (Static Site Hosting) تقدمها منصة GitHub لتحويل ملفات المشروع المخزّنة في مستودعك مباشرة إلى موقع ويب منشور ومتاح عبر الإنترنت.

طبيعة الخدمة وكيف تختلف عن الخوادم التقليدية

تقوم GitHub Pages بقراءة ملفات HTML وCSS وJavaScript (أو مخرجات أدوات البناء الثابتة مثل Jekyll أو مسارات GitHub Actions) من مستودع المشروع، ثم تنشرها تلقائياً على رابط ويب آمن يعمل ببروتوكول HTTPS. تُعالج كل شيفرة التفاعل داخل متصفح الزائر مباشرة دون الحاجة إلى تشغيل خادم خلفي.

نشر مباشر من المستودع يرتبط الموقع مباشرة بملفات الشيفرة؛ فأي تحديث محفوظ في الفرع المحدد ينعكس على الموقع تلقائياً.
مصممة للمحتوى الثابت مثالية للصفحات التعريفية والتوثيق والمواقع التعليمية التي لا تحتاج معالجة خادمية.
تشفير HTTPS مدمج تدعم تفعيل الاتصال المشفّر للنطاق الافتراضي والنطاقات المخصصة لتعزيز أمان التصفح.
دون إعداد بنية تحتية لا يحتاج الطالب أو المطوّر إلى تهيئة خادم ويب أو إدارة نظام تشغيل أو لوحات استضافة معقدة.

القسم السادس • Technologies

التقنيات الأساسية المشاركة في المنظومة

تتكامل سبع تقنيات رئيسية لتقديم موقع ثابت سريع وآمن من مرحلة البناء المحلي وحتى العرض في متصفح المستخدم.

الهيكلة

HTML

تحدد البنية الدلالية لصفحات الموقع الثابت ومحتواها النصي والروابط والعناصر، وتُعدّ index.html نقطة الدخول الافتراضية للموقع.

التنسيق البصري

CSS

تتحكم في الهوية البصرية والألوان والتخطيط المتجاوب واتجاه RTL والانتقالات، مما يجعل الموقع قابلاً للعرض بسلاسة على الهواتف والحواسيب.

التفاعل الأمامي

JavaScript

تضيف التفاعل المباشر داخل متصفح الزائر (مثل التنقل بين المخططات والخطوات والرسوم المتحركة) دون الحاجة إلى معالجة على خادم خلفي.

إدارة الإصدارات

Git

نظام إدارة الإصدارات الموزّع الذي يتتبع تعديلات ملفات المشروع محلياً، ويتيح العودة إلى النسخ السابقة ودفع التحديثات بدقة وأمان.

الاستضافة البرمجية

GitHub

المنصة السحابية التي تستضيف مستودعات Git وتنظم الفروع وتوفر واجهة الإعدادات والتعاون، وتشكّل المصدر المباشر لملفات الموقع.

الأمان والتشفير

HTTPS

بروتوكول الاتصال الآمن الذي يشفّر البيانات المتبادلة بين خوادم GitHub Pages ومتصفح الزائر لضمان سلامة المحتوى وخصوصية الاتصال.

النشر المؤتمت

GitHub Pages Deployment

الآلية السحابية التي تلتقط تحديثات الفرع المصدري أو مخرجات GitHub Actions، وتجهّز الملفات الثابتة وتنشرها على الرابط العام تلقائياً.

القسم السابع • Advantages

المميزات الرئيسية لخدمة GitHub Pages

تجمع الخدمة بين بساطة الإعداد والاعتماد على بنية سحابية موثوقة تخدم الطلاب والمطورين وفرق التوثيق.

سهولة الاستخدام

يمكن تفعيل النشر في خطوات قليلة مباشرة من إعدادات المستودع دون الحاجة إلى خبرة في إدارة الخوادم أو تهيئة لوحات التحكم التقليدية.

استضافة المواقع الثابتة

توفر بيئة مستقرة وسريعة مخصصة لتقديم ملفات HTML وCSS وJavaScript والأصول الثابتة بكفاءة عالية.

التكامل مع GitHub

تندمج الخدمة عضوياً مع مستودع الشيفرة والفروع وسجل التعديلات، مما يوحد مكان التطوير ومكان النشر في منصة واحدة.

دعم HTTPS

تتيح فرض التشفير عبر HTTPS لحماية اتصال الزوار بالصفحات المنشورة وتعزيز موثوقية الموقع في المتصفحات الحديثة.

سهولة تحديث الموقع

بمجرد حفظ تعديل جديد في المستودع أو دفعه عبر Git، تبدأ عملية نشر جديدة تلقائياً لتحديث النسخة الحية من الموقع.

إمكانية استخدام النطاق الخاص

يمكن ربط الموقع بنطاق مخصص (Custom Domain) مثل example.com بدلاً من الاقتصار على نطاق github.io الافتراضي.

القسم الثامن • Limitations

القيود التقنية التي يجب معرفتها بوضوح

فهم حدود أي خدمة سحابية جزء أساسي من التصميم الهندسي السليم؛ ولذلك توضّح النقاط التالية الحالات التي لا تغطيها GitHub Pages وحدها.

لا يشغّل Backend تقليدياً

لا يمكن تنفيذ شيفرات جهة الخادم مثل PHP أو Python أو Node.js مباشرة على خادم GitHub Pages؛ إذ يقتصر دوره على تسليم الملفات الثابتة.

لا يوفر قاعدة بيانات مدمجة

لا تتضمن الخدمة محرك قواعد بيانات مدمجاً (مثل MySQL أو PostgreSQL) لتخزين حسابات المستخدمين أو المعاملات الديناميكية.

لا يناسب جميع التطبيقات الديناميكية

المتاجر الإلكترونية المتكاملة أو أنظمة إدارة المحتوى الخادمية أو الأنظمة التي تتطلب مصادقة وجلسات خادمية تحتاج إلى خدمات Backend أو استضافة تطبيقات مستقلة.

وجود حدود وشروط استخدام

تخضع الخدمة لضوابط وسياسات استخدام من GitHub (تشمل سعة الموقع ومعدل النشر والنطاق الترددي والاستخدام المسموح به) ينبغي مراجعتها في التوثيق الرسمي.

القسم التاسع • Comparison

مقارنة بين GitHub Pages والاستضافة التقليدية

مقارنة مفاهيمية وتقنية تساعد على اختيار النموذج الأنسب وفق طبيعة المشروع ومتطلباته البرمجية.

معيار المقارنة GitHub Pages الاستضافة التقليدية (Traditional Hosting)
إدارة الخادم مُدارة بالكامل من قبل GitHub؛ لا يحتاج المستخدم إلى إعداد خادم أو متابعة تحديثات النظام أو الصيانة. تتطلب قدراً من الإدارة والإعداد (مثل لوحات التحكم أو إعدادات الخادم وتحديثات البيئة وشهادات الأمان).
سهولة النشر سريعة ومباشرة؛ يُنشر الموقع تلقائياً بمجرد رفع الملفات أو دفع التحديثات إلى الفرع المحدد في المستودع. تعتمد غالباً على رفع الملفات عبر FTP/SFTP أو لوحة تحكم أو إعداد خطوط نشر إضافية.
نوع التطبيقات مخصصة للمواقع الثابتة (HTML, CSS, JS) ومخرجات مولّدات المواقع الثابتة دون Backend خادمي. تدعم المواقع الثابتة والتطبيقات الديناميكية مع لغات الخادم (مثل PHP, Python, Node.js) وقواعد البيانات.
التحكم بالبنية التحتية تحكم محدود يركز على إعدادات النشر والمصدر والنطاق، بينما تبقى البنية التحتية مُدارة ومخفية عن المستخدم. تحكم أوسع في إعدادات الخادم والبرمجيات والملفات التكوينية وقواعد البيانات حسب نوع خطة الاستضافة.
التكلفة متاحة ضمن حسابات GitHub للمستودعات العامة دون رسوم استضافة منفصلة (وتخضع بعض الميزات المتقدمة لخطط GitHub). تتطلب عادةً اشتراكاً دورياً لدى مزوّد خدمة الاستضافة يختلف حسب الموارد والخدمات المضمّنة.

القسم الحادي عشر • Conclusion

أهمية خدمات الاستضافة السحابية في العصر الحديث

تُجسّد خدمة GitHub Pages أحد أبرز أهداف الحوسبة السحابية: إزالة الحواجز التقنية بين الفكرة وإتاحتها للعالم. فمن خلال تحويل مستودع برمجي بسيط إلى موقع ثابت آمن وسريع، تمكّن هذه الخدمة الطلاب والمطورين من التركيز على جودة المحتوى والتصميم والهندسة البرمجية بدلاً من الانشغال بتعقيدات الخوادم التقليدية — مع وعي كامل بحدود الاستضافة الثابتة ومتى نحتاج إلى بنية خلفية متكاملة.
